# 松山工場 新事務所｜建築コンセプト・ストーリー

「迎える。守る。支える。」を、7シーン・45秒の模型と図面で伝える完成版Webプレゼンテーションです。Three.js 0.180.0 / GSAP 3.13.0 / Vite 7.1.7を使用しています。

## すぐに見る

Windowsでは `start.cmd` をダブルクリックして、Chromeで `http://127.0.0.1:5173/` を開きます。Node.js 22以降が必要です。このPCのCodex同梱Nodeにも対応しています。ビルド済みの `dist/` が同梱されているため、閲覧時にライブラリのインストールは不要です。終了は起動したターミナルで Ctrl+C。5173が使用中なら、既に起動したプレゼンを確認してください。

別のポートで閲覧するときは PowerShell で次を実行します。

```powershell
$env:PORT='5174'
node server.mjs
```

`index.html` の直接ダブルクリックではJSONと画像を読込できません。HTTPサーバー経由で開いてください。閲覧にはインターネット接続は不要です。公開版はSitesの所有者限定です。

## 操作

|操作|方法|
|---|---|
|自動再生|読込後に開始。45秒で停止。動きを減らすOS設定の場合は手動開始|
|再生・停止|丸い再生ボタン / Space|
|シーン移動|下部の7項目 / ‹ › / 左右矢印|
|シーク|下部スライダー。往復しても同じ状態へ戻る|
|再生速度|0.5 / 1 / 1.5 / 2倍|
|回転・ズーム|模型をドラッグ / ホイール。自由視点にすると再生を一時停止|
|カメラリセット|右上の戻る矢印。シーン移動時も既定視点へ戻る|
|模型設定|スライダーのアイコン。吹き出し、透明度、屋根、階表示|
|全画面|ヘッダー右端のアイコン|
|PNG保存|カメラのアイコン。現在の模型、注釈タイトル、シーン名を保存|
|UI非表示|目のアイコン / H。説明文と模型を残して操作UIを隠す|
|資料の確認|左の大きな原図 / 右上「資料と設計の根拠」。図面ビューは最大600%の拡大とドラッグ移動|
|立面の照合|模型設定の「図面と照合」で南・東・北・西立面、北西側、屋上設備、玄関外構を選択|
|GLB / GLTF読込|模型設定からローカルファイルを選択。端末内で読込・外部送信なし|

ダイアログを開くと再生を停止します。再開は再生ボタン。PNGは模型ビューの画像で、ページ全体のスクリーンショットではありません。

## 編集とビルド

Node.js 22以降とpnpmを利用します。

```powershell
pnpm install
pnpm dev
pnpm build
```

`public/` を編集した場合、開発サーバーはそのまま変更を読みます。完成版の `dist/` と公開版へ反映するには再ビルドが必要です。

## 別案件へ差し替える

|JSON|変更対象|
|---|---|
|project.json|案件名・施主・場所・資料・事実・確認事項・外部モデル|
|scenes.json|タイトル・文章・開始時間・継続時間・演出状態・注釈ID|
|annotations.json|吹き出し本文、3Dアンカー、階番号|
|circulation.json|利用者ごとの色・経由点・意味|
|zoning.json|領域の階、中心、寸法、色|
|facade.json|南・東・北面の窓割、サッシ、庇、屋上目隠し、看板|
|landscape.json|スロープ・着床・植栽帯・駐車区画・歩道・駐輪場|
|massing.json|棟の寸法、階高、平面画像、屋上、計画範囲|
|camera.json|各シーンの視点、注視点、表示範囲|
|style.json|背景・模型・ガラス・機能色|

単位はm、Xが東、-Zが北、Yが高さ。事務所の中心が原点です。`annotations.level` が数値のとき、アンカーYはその階の床からの相対高さで、階の分解移動に追従します。`level: "roof"` は絶対高さに屋根の分解量を加えます。`level: null` は敷地の絶対座標です。

シーンの開始時間は累積にし、継続時間の合計と `project.duration` を一致させます。`state` の `explode` は階分解、`cut` は壁透過・平面表示、`routes` は動線、`zones` はゾーニング、`bcp` は重要機能、`light` は北側自然光の模式線です。現在の実装は7シーン45秒用の時間UIなので、総尺やシーン数を変える際は `src/main.js` の表示時間・ナビゲーションも更新してください。

棟形状は現在の案件向けの簡易模型生成です。主要寸法・階高・カメラ・文章はJSONで変更できます。別案件の大きく異なる形状・窓割・内部3D詳細は `src/architecture.js` / `src/landscape.js` の生成関数を調整するか、GLBモデルを読込みます。

`project.modelUrl` を `models/project.glb` のような相対URLへ設定し、`public/models/` に置きます。`modelTransform` で縮尺・Y回転（ラジアン）・位置を設定します。現在は説明模型に重ねて表示します。差し替える場合は `office.visible=false` を設定し、注釈・動線・カメラもモデルの座標系に合わせて調整してください。ローカル選択は単一GLBまたは画像・バッファ埋込GLTFに対応。外部参照を持つGLTFはURL配置で利用します。

UIの階・屋根表示と分解は説明模型に適用し、追加モデルのパーツは操作しません。実案件で追加モデルに同じ操作を適用する場合は、そのモデルのノード名を階・屋根へ対応付けてください。

## 原図の位置付け

原資料は大阪ソーダ松山工場新事務所の提供4 PDFです。3Dモデルは提供されていないため、寸法図・立面・鳥瞰に基づく簡易模型を制作しました。正確な室配置は、各階に重ねた原図平面で伝えています。模型の壁・窓・設備・植栽・車両・動線は概略です。施工BIM、環境解析、構造計算の代替ではありません。

資料の版差、1階FL、災害対策会議室、浸水想定の扱いは `ANALYSIS.md` および画面内「資料と設計の根拠」に記録しています。

技術資料： [Three.js](https://threejs.org/docs/) / [GSAP Timeline](https://gsap.com/docs/v3/GSAP/Timeline/) / [Viteの静的配信](https://vite.dev/guide/static-deploy.html)。

## プロジェクターで映す

初期表示は「投影用表示 ON」。太いゴシック体と濃い文字色を使い、2560幅で見出し62px・本文26px・吹き出し30/24pxへ拡大しています。ヘッダーの切替で通常表示へ戻せます。プレゼン時は全画面表示を選び、Hで操作UIと原図サムネイルを隠すと、模型と大きな説明文に集中できます。原図はクリックして画面全体で表示し、最大600%まで拡大可能です。

西面は追加参考CG WS000238.JPGを反映しています。屋上囲いは横方向のフレクサラム、設備は大小2列と別置BOX・階段室で構成しています。西面の開口・機器の細寸法は参考画像からの概形です。
