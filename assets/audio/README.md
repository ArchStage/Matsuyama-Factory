# Piano recordings

University of Iowa Electronic Music Studios, Musical Instrument Samples.
Steinway & Sons model B, pianissimo, performed by Evan Mazunik, recorded by Michael Cash, November 2001. Collection created by Lawrence Fritts.

Source: https://theremin.music.uiowa.edu/MISPiano.html
Permission: https://theremin.music.uiowa.edu/MIS.html
The official collection page permits downloading and use for any projects without restrictions (checked 2026-10-15).

Edits: onset and tail trimmed to 2.2 seconds, DC removed, peak normalized, edge fades, converted to stereo PCM16 WAV / 44.1kHz. Playback uses a gentle low-pass filter and shorter release envelope. See CREDITS.json for individual source files, hashes and edit values.
